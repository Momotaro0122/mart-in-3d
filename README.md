# Mart in 3D

Martin / MingHan Lee — rigging and tools portfolio.

Forked from [Amanda Yang’s website](https://github.com/amandayyang15/amandayyang15.github.io). Original Git history and font assets are retained. Design, illustration, content and interactions are customized for Martin. Original files in assets/ remain from upstream but are not referenced or included in the deployed site.

Content source: https://mart-in-3d.odoo.com/ (reviewed November 3, 2026). Reel links and WIP status come from that site. Decorative artwork is illustrative, not a screenshot of a reel. Home address and phone number are omitted.

No framework or install is needed. Serve the repository with any static server. Edit index.html, style.css and main.js. GitHub Pages can serve from the repository root on main. For Sites, copy these files, links.html and fonts/ to dist/.

Features: responsive layout, reduced-motion support, keyboard focus indicators and accessible project filters. Reel links open on their original platforms.
